## Overview

This repository contains the code used for data preparation, descriptive analyses, mixed-effects regression modelling, sensitivity analyses, and additive Bayesian network (ABN) modelling investigating the association between genetic susceptibility and phenotypic characteristics of ruptured intracranial aneurysms (RIA). The repository is intended to support transparency, reproducibility, and reuse of the computational workflow underlying the study findings.

As the original study data set contains sensitive patient-level information, it cannot be publicly distributed. Instead, a synthetic data set generated using the `synthpop` package is provided to demonstrate the structure of the data and enable execution of the analysis scripts.

## Quick Start

Cloning the repository:

``` bash
git clone https://github.com/learbuehrer/ria-genetic-susceptibility-phenotypes.git
cd ria-genetic-susceptibility-phenotypes
```

Choose the workflow of interest:

-   Local analyses: run the scripts in `R/scripts/`:\
    Restore the R environment:

    ``` r
    install.packages("renv") 
    renv::restore()
    ```

    Run the analysis scripts in the following order:

    ``` text
    R/scripts/

    00_setup.R
    01_descriptives.R
    02_regressions.R
    03_sensitivity.R
    ```

-   HPC analyses (ABN/MCMC): see `hpc/README.md`

### `R/`

Contains the R code used for the analyses.

-   `functions/` contains reusable functions for data processing, statistical modelling, and visualisation.
-   `analysis/` contains the analysis scripts executed for the publication.

### `hpc/`

Contains scripts required to run computationally intensive analyses on the high-performance computing (HPC) environment. The `submit.sh` script provides the corresponding job submission workflow.

### `data/synthetic/`

A synthetic data set generated from the original study data using the R package `synthpop` (n = 2000).

The synthetic data set preserves the overall structure and statistical characteristics of the original data set while containing no real study participants.

The data set is provided solely to:

-   demonstrate the analytical workflow,
-   enable execution of the code,
-   facilitate reproducibility of the computational analyses.

The synthetic data set should **not** be used for scientific inference or interpretation of effect estimates.

### `figures/` and `tables/`

Figures and tables generated by the analysis scripts are not version-controlled and therefore are not included in the repository. They can be regenerated locally.

## Software environment

The primary analysis workflow and the HPC workflow maintain separate software environments. The top-level `renv.lock` file is used for the local analyses in `R/`, whereas HPC-specific dependencies are documented separately within `hpc/`.

Package versions are managed using [`renv`](https://rstudio.github.io/renv/). The `renv.lock` file records the R package versions used for the analysis. To initialise the project environment after cloning the repository:

``` r
install.packages("renv")
renv::restore()
```

This installs the package versions recorded in `renv.lock`. To inspect the current project environment:

``` r
renv::status()
```

## Data availability

The underlying study data are not publicly available because they contain sensitive patient-level information and/or are subject to data-sharing restrictions. The synthetic data set included in this repository is provided solely for demonstration and testing purposes. It does not contain real patient-level observations and cannot be used to reproduce the numerical results reported in the publication.
